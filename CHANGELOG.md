# Changelog

## 0.1.0 — Unreleased

- Button-only Omarchy plugin with a read-only tray assignment cheat sheet.
- Compact icon-first rows; physical names, source keys, and full actions remain
  available on hover and to assistive technology.
- Small direct JSON plugin CLI for device discovery, setup, inspection, schema,
  guidance, binding, unbinding, atomic configuration batches, and owned removal.
- A 16-button NVIDIA SHIELD 2019 preset; one configured remote for the MVP.
- Device-specific Lua/XKB routing with conflict checks, validation, reload, and
  rollback rather than replacement of laptop/global shortcuts.
- Center/OK defaults to Return; mic calls the separately installed
  `omarchy-dictation toggle` command. Other buttons retain native behavior.
- Portable agent instructions, offline release regressions, deterministic indexed
  source packaging, and an Ubuntu 24.04 CI template.
- No audio implementation, Bluetooth bridge, recording, audio binary/build,
  root service, provider account, or network requirement.

Release publication, physical-device acceptance, and login/reboot verification
are not asserted by this changelog.
